# MihomoSurgeBridge 统一图标系统设计

## 目标

参考用户提供的视觉稿，同时更新 macOS 应用图标与顶部菜单栏状态图标。两类图标共享同一个“三节点桥接”标志，并针对 1024px 应用图标与约 18px 菜单栏图标分别适配，保证风格统一和小尺寸辨识度。

参考图只提供视觉方向；其中的文字、产品名称和功能说明不作为需求。

## 1. 共享标志

标志由以下几何构成：

- 两个等大的上方圆形节点。
- 一个位于中轴线上的下方圆形节点。
- 两个上方节点之间的水平桥接关系。
- 两个上方节点分别连接到下方节点的斜向链路。

整体保持水平对称，节点和链路使用一致的视觉重量。标志不包含字母、文字或第三方产品 Logo。

## 2. 应用图标

应用图标使用接近黑色的圆角方形底板，四周保留标准 macOS 图标安全边距。共享标志使用银白色节点与连接件，允许非常轻微的高光和柔和阴影来贴近参考稿，但不使用霓虹、彩色渐变、玻璃拟态或复杂纹理。

尺寸适配规则：

- 1024px、512px 和 256px：顶部水平关系使用三个圆点，保留克制的银白层次。
- 128px 和 64px：减少高光与阴影强度，连接件适当加粗。
- 32px 和 16px：顶部三个圆点简化为一条水平实线，标志使用高对比纯色，确保像素级辨识度。

现有 `Resources/AppIcon-1024.png` 与 `Resources/AppIcon.icns` 被新设计替换，文件路径保持不变。`scripts/generate-app-icon.swift` 负责可复现地生成母版，`scripts/generate-app-icon.sh` 继续生成完整 `.icns` 尺寸集。

## 3. 菜单栏状态图标

菜单栏使用与应用图标相同的节点比例和连接角度，但采用更粗、更简单的模板化几何。图标不复用应用图标底板，不使用位图缩放。

状态映射：

- 运行中：明亮的三节点标志，并在标志下方显示一个独立实心状态点。
- 连接中：三节点标志整体使用中性灰色，不显示彩色提示。
- 异常：主体保持中性颜色，底部节点使用系统红色。
- 已暂停：灰色三节点标志置于低对比圆形底中。

菜单栏图标需要同时适配浅色和深色菜单栏。除异常状态外，颜色跟随系统前景色；异常红色使用系统语义色。

当前状态来源沿用现有 Mihomo 状态模型：运行、检查/连接、失败、停止分别映射到上述四种外观。本次不增加新的进程状态或状态切换规则。

## 4. 实现方式

采用代码原生绘制而非生成式位图：

- 应用图标通过 AppKit 绘制到 1024×1024 PNG，再生成 `.icns`。
- 菜单栏通过 SwiftUI 自定义 `Shape` 或 `Canvas` 绘制，复用共享比例常量。
- 应用图标可保留克制的材质层次；菜单栏版本保持扁平和高对比。

这种方式可以避免位图在 Retina 缩放、浅色/深色菜单栏和 16px/32px 图标尺寸下模糊，也能保证后续修改时两套图标不会偏离。

## 5. 验收

- 应用图标与菜单栏图标都能明确识别为同一个三节点桥接标志。
- 应用图标在 1024px、128px、32px 和 16px 下保持结构清楚。
- 菜单栏四种状态在浅色和深色外观下可辨识，异常状态是唯一彩色状态。
- `AppIcon.icns` 格式有效并被应用包正确引用。
- Release 应用构建、签名和 ZIP 解压验签通过。
- 不改变应用名称、Bundle Identifier、Dock 显隐、Mihomo 生命周期或订阅行为。

## 范围边界

本次只更新图标视觉和菜单栏图标渲染，不修改管理窗口 UI、状态机业务逻辑、应用文案或其他品牌物料。
