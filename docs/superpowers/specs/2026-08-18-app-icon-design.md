# MihomoSurgeBridge App Icon 设计规格

## 目标

为 macOS 应用提供一个正式、清晰的 Dock 图标，替换当前缺少图标资源时显示的系统空白占位图。

## 已确认方向

- 采用第二轮 A「极简桥」。
- 现代扁平风格：无渐变、无发光、无纹理、无拟物阴影。
- 靛蓝纯色圆角方形底，中央使用纯白的极简桥形符号。
- 不使用文字、字母缩写或第三方产品 Logo。
- 桥的两端代表 Surge 与 Mihomo，中间连接表示转换与桥接。
- 优先保证 16px、32px 和 64px 下的轮廓辨识度，不增加小尺寸会糊成一团的细节。

## 产物与接入

- 生成并保留 1024×1024 PNG 母版。
- 生成 macOS 标准尺寸 `AppIcon.icns`。
- 在 `Info.plist` 中声明 `CFBundleIconFile`。
- 打包脚本把 `AppIcon.icns` 复制到应用包的 `Contents/Resources`。
- 构建号递增，减少 macOS 图标缓存继续显示旧占位图的概率。

## 验收

- 应用包包含有效的 `AppIcon.icns`，`Info.plist` 引用正确。
- 重新打包后代码签名校验通过。
- 图标在 32px 预览下仍能看出“两个端点由桥连接”的主体结构。
- 关闭主窗口后的 Dock 显隐逻辑保持不变。

## 范围边界

本次只修复应用图标资源与打包接入，不重做菜单栏图标、品牌系统、启动页或其他界面视觉。
